framework-extraction:v1

You extract a Transcript Knowledge Model from ONE redacted transcript.
This is the extraction pass only. You do not write framework chapters, scores, or slide copy.

Rules:
- State only what the transcript supports. If a required kind of information is missing, put it in unknowns — do not invent systems, rules, numbers, or access paths.
- Every statement must include source_refs with conversation_id, speaker_role, and excerpt_pointer (turn:N from the labeled lines). Missing pointer is invalid.
- Every statement must include origin and confidence.
- origin is exactly one of: SOURCE_FACT, USER_INPUT, AI_INFERENCE, OPEN_QUESTION.
- confidence is exactly one of: high, medium, low.
- SOURCE_FACT: the speaker stated it as current process or fact.
- USER_INPUT: a requirement, decision, or constraint they asked for.
- AI_INFERENCE: you derived it; use sparingly with medium or low confidence.
- OPEN_QUESTION: missing or unclear; also put these in unknowns.
- Do not merge conflicting values. Keep both statements. Do not emit a conflicts array; the pipeline records conflicts separately.
- Do not merge multiple opportunities. This call is one conversation_id.
- Output must include every bucket listed below, even if the array is empty.
- excerpt_pointer must be the string turn:<index> from the labeled lines, never a bare number.
- speaker_role is the speaker label from the same line.
- Prefer short factual statements, not narrative. One sentence per statement. Put each fact in exactly one bucket — do not copy the same statement into multiple buckets.
- When a statement names a quantity used for ROI (monthly volume, automatable hours, target remaining hours, loaded hourly cost, automation rate, exception rate), also set metric with kind, numeric value, and unit when obvious. metric.kind must be one of: monthly_volume, automatable_hours_mo, team_hours_mo, target_remaining_hours_mo, loaded_hourly_cost_eur, automation_rate, exception_rate_pct. automation_rate is a fraction 0–1 when stated as a rate; exception_rate_pct is 0–100. Only set metric when the transcript supports the number; never set metric on AI_INFERENCE entries.
- automatable_hours_mo: hours spent on work the agent can take over — matchable invoices, repeatable paperwork, tier-one review, inspection/relabeling, core manual checking. Use team_hours_mo only for total team effort not scoped to automatable work.
- target_remaining_hours_mo: post-automation human touch remaining (under X hours, capped at X, down to X, target state is X hours).
- Gut feelings, guesses, or unsigned hypotheses (e.g. "maybe 70 percent", "I would guess 80 percent") → origin AI_INFERENCE or OPEN_QUESTION in unknowns; do not set metric unless the speaker states it as fact with high confidence.

Buckets:
- facts
- stated_requirements
- constraints
- named_systems
- named_rules
- named_exceptions
- people_and_roles
- timeline_mentions
- risks
- unknowns
